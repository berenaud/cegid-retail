## Français

### À quoi sert cette page

Cette page publie dans Aha! une feature générée par le skill Claude « Aha! feature ». Le skill rédige la feature, puis produit un lien vers cette page. Il suffit de l'ouvrir, de choisir la release (et si besoin l'épic et l'initiative), puis de cliquer sur « Push to Aha! ».

### Fonctionnement

1. Le skill encode la feature dans le lien, après `#data=`.
2. La page décode ces données dans le navigateur. La partie après `#` n'est jamais envoyée au serveur, donc la feature ne transite pas par GitHub.
3. La page récupère les releases, épics, initiatives et personas du produit via l'API de `cegid.aha.io`.
4. Au clic sur « Push to Aha! », la feature est créée dans Aha! à ton nom.

Ouverte sans lien généré par le skill, la page affiche un écran « pas de données ». C'est normal.

### Première utilisation : le token Aha!

Chaque utilisateur utilise sa propre clé API Aha!, à créer dans Aha! : **Settings > Developer > API Keys** (`https://cegid.aha.io/settings/api_keys`).

- La clé est saisie une fois, puis gardée dans le stockage local de ton navigateur.
- Elle n'est envoyée qu'à `cegid.aha.io`, jamais ailleurs.
- Les droits de ta clé s'appliquent : tu ne peux publier que là où ton compte Aha! a les droits.
- Le bouton « Effacer le token » la supprime du navigateur.

### Version de la page

Le footer affiche la date du dernier commit qui a modifié `index.html`, avec un lien vers ce commit. L'information est gardée en cache 10 minutes. Le bouton ↻ force sa mise à jour.

Si la page elle-même semble ancienne après une mise à jour, fais un rechargement forcé : **Ctrl+Shift+R** (Cmd+Shift+R sur Mac).

### Problèmes fréquents

- **Erreur 401** : clé API invalide ou expirée. Clique sur « Changer de token ».
- **Erreur réseau** : vérifie ta connexion, puis ouvre la console du navigateur (F12) pour voir le détail.
- **Écran « pas de données »** : le lien a été tronqué ou copié sans sa partie `#data=`. Régénère-le depuis le skill.

### Maintenance

- La page tient en un seul fichier, `index.html`, sans dépendance externe.
- Pour la mettre à jour : remplacer `index.html` dans le dépôt, attendre la fin du déploiement (onglet Actions), puis tester.
- **Ne jamais commiter de token, d'export Aha! ou d'exemple de lien contenant une vraie feature.** Le dépôt est public, historique compris.
- Les données affichées dans la page doivent toujours passer par `escHtml()` ou `textContent`, jamais directement par `innerHTML`.

### Format des données

Le lien contient un JSON encodé en base64url (UTF-8) :

```json
{
  "name": "Titre de la feature (80 caractères max conseillés)",
  "product": "Clé du produit Aha!",
  "tags": "tag1, tag2",
  "personas": ["Persona A"],
  "context": "…",
  "objective": "…",
  "included": ["…"],
  "excluded": ["…"],
  "criteria": ["…"],
  "dependencies": "…",
  "slices": ["…"],
  "skill_version": "x.y"
}
```

## English

### What this page does

This page publishes to Aha! a feature generated by the "Aha! feature" Claude skill. The skill writes the feature, then produces a link to this page. Open it, pick the release (and optionally the epic and initiative), then click "Push to Aha!".

### How it works

1. The skill encodes the feature in the link, after `#data=`.
2. The page decodes this data in the browser. The part after `#` is never sent to the server, so the feature never goes through GitHub.
3. The page fetches the product's releases, epics, initiatives and personas from the `cegid.aha.io` API.
4. When you click "Push to Aha!", the feature is created in Aha! under your name.

If opened without a link generated by the skill, the page shows a "no data" screen. This is expected.

### First use: your Aha! token

Each user uses their own Aha! API key, created in Aha!: **Settings > Developer > API Keys** (`https://cegid.aha.io/settings/api_keys`).

- The key is entered once, then kept in your browser's local storage.
- It is only sent to `cegid.aha.io`, never anywhere else.
- Your key's permissions apply: you can only publish where your Aha! account has access.
- The "Clear saved token" button removes it from the browser.

### Page version

The footer shows the date of the last commit that changed `index.html`, linked to that commit. This information is cached for 10 minutes. The ↻ button forces a refresh.

If the page itself looks outdated after an update, do a hard reload: **Ctrl+Shift+R** (Cmd+Shift+R on Mac).

### Common issues

- **401 error**: invalid or expired API key. Click "Change token".
- **Network error**: check your connection, then open the browser console (F12) for details.
- **"No data" screen**: the link was truncated or copied without its `#data=` part. Generate it again from the skill.

### Maintenance

- The page is a single file, `index.html`, with no external dependency.
- To update it: replace `index.html` in the repository, wait for the deployment to finish (Actions tab), then test.
- **Never commit a token, an Aha! export or a sample link containing a real feature.** The repository is public, history included.
- Data displayed in the page must always go through `escHtml()` or `textContent`, never directly through `innerHTML`.

### Data format

The link contains a base64url-encoded (UTF-8) JSON object:

```json
{
  "name": "Feature title (80 characters max recommended)",
  "product": "Aha! product key",
  "tags": "tag1, tag2",
  "personas": ["Persona A"],
  "context": "…",
  "objective": "…",
  "included": ["…"],
  "excluded": ["…"],
  "criteria": ["…"],
  "dependencies": "…",
  "slices": ["…"],
  "skill_version": "x.y"
}
```
